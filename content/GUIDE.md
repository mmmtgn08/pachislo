# 台本作成ガイド（毎日の自動タスクが読むファイル）

このファイルはチャンネルの「編集方針」です。自由に書き換えてOK。
毎日の自動タスク（Claude）はこのガイドと `content/history.jsonl` を読んで、その日の台本を1本作ります。

## チャンネル像
- ターゲット: パチスロ好きの若い大人の打ち手（いわゆる「ドパガキ」層、18歳以上）
- キャラ:
  - **ずんだもん**（zundamon）: ボケ担当のドパガキ。語尾「〜のだ」。調子に乗る→痛い目を見る
  - **四国めたん**（metan）: ツッコミ・司会。お嬢様口調で冷静に刺す
- 「読み上げ」ではなく**2人の会話劇**にする。同じ人が3行以上連続で話さない

## 伸びる構成（必ずこの流れ）
ショートは「最初の1〜2秒で離脱されない」「最後まで見られる」「もう1回見られる」ほど伸びる。

| パート | 行 | やること |
|---|---|---|
| ① フック | 1行目 | `hook` と同じ内容を言い切る。**冒頭1行目は画面中央にhookが特大表示されるだけ**（telopは表示されない） |
| ② 期待 | 2行目 | 「3つ紹介」「最後がヤバい」など、最後まで見る理由を作る（①に含めても可） |
| ③ 本編 | 3〜7行目 | ネタ→ツッコミ（またはリアクション）を交互に。1ネタ2行が基本 |
| ④ オチ | 終盤 | 一番強いネタは最後に置く。`emphasis: true` + `se` で盛り上げる |
| ⑤ 締め | 最終行 | コメント誘導（答えやすい質問）。最終行には自動で「チャンネル登録」ボタンが表示される |

### フックの型（毎回どれかを使う。同じ型を3日連続にしない）
- **診断・挑戦型**: 「3個当てはまったら手遅れです」「これ分かったら上級者」
- **数字・衝撃型**: 「月10万負けた人の末路」「天井まで平均◯◯円」
- **否定型**: 「その打ち方、損してます」「それ、設定6じゃないです」
- **共感型**: 「スロッターしか分からない瞬間」「負けた日の帰り道あるある」
- **問いかけ型**: 「朝イチ、何回転で見切る？」

### テンポのルール
- 1行の読み上げは **15〜35文字**。長い説明は2行に割る
- 全体 **7〜10行・25〜45秒**
- テロップは読み上げの要約。**1行12文字以内×2行まで**が理想（例: 「①給料日\n先に見るのは新台情報」）
- 番号付きネタは telop の頭に「①②③」を付ける

### 最後まで見られる・登録される工夫
- **シリーズ化**: `series` を必ず付ける（下の一覧から選ぶ）。動画に「ドパガキ図鑑 #12」のように回数が自動表示され、続きを見たくなる
- **コメント誘導**: 最終行は「数字だけコメントして」「AとBどっち？」など**1秒で答えられる質問**にする
- **ループ**: できれば最終行の言葉が1行目につながるようにする（例: 最後「…で、あなたは何個？」→ 最初「3個当てはまったら手遅れ」）
- 「続きは明日」「次回◯◯編」で次の動画への期待を作るのもOK（週2回まで）

### シリーズ一覧
- `ドパガキ図鑑`: あるある・診断・生態
- `スロ雑学`: 天井・設定・確率・機械割などの豆知識
- `収支の現実`: 負け額・収支管理・お金の話（収支をつける大切さに着地させる）
- `ドパガキランキング`: やりがちな行動ランキング（3位→2位→1位の逆順で発表）
- `迷言集`: スロッターの迷言・言い訳

## 演出の指定（lines の各行で使える）
- `emphasis: true`: テロップ赤＋画面揺れ＋フラッシュ。**オチ・衝撃の行だけ**（1本に1〜3回）
- `se`: 行頭で鳴る効果音
  - `don`: ドン！（フック・衝撃）
  - `pop`: ポン（ネタ紹介・場面転換）
  - `peka`: ペカッ（当たり・良いこと）
  - `boo`: ブッブー（失敗・ダメな例）
  - `chan`: チャリーン（お金の話）
  - `kira`: キラキラ（締め・正解）
  - `whoosh`: シュッ（切り替え）
  - 毎行付けるとうるさいので、全体の半分くらいの行に
- `reaction`: テロップ右上に出るスタンプ（6文字以内）。例: 「草」「！？」「普通？」「それな」「終わり」

## 守るルール（必須）
- 18歳未満の遊技を勧めたり、未成年を想定した表現をしない
- 借金・生活費での遊技を肯定・推奨しない（ネタにする場合は「ダメな例」として扱う）
- 「必ず勝てる」「確実に設定6」など断定的な攻略・勝利保証をしない
- 実在の店舗名・個人名を出さない。機種名はOKだが、スペックや数値は確実なものだけ。曖昧なら一般論にする
- 過去の台本（history.jsonl のタイトル/フック）と同じネタを使わない

## タイトル・概要欄
- `title`: **全角30文字以内**。フックの言い換え＋数字か強い言葉（「手遅れ」「9割が知らない」「末路」）。「#shorts」は自動付与
- `description`: 1〜2文。コメント誘導の質問を入れる
- `tags`: 5〜8個（パチスロ / スロット / ドパガキ / シリーズ名 など）

## 台本JSONの形式
`content/examples/sample.json` を参照。
- `theme`: あるある / 設定判別 / 収支 / 雑学 / ランキング / 名言 / ネタ（背景色が変わる）
- `series`: 上のシリーズ名（回数は自動で数える）
- `hook`: 冒頭に特大表示＆上部に常時表示する見出し（8〜16文字、`\n` で2行に）
- `lines`: 7〜10行（最大16）
  - `speaker`: `zundamon` か `metan`
  - `text`: 読み上げ文（1行70文字以内、全体で380文字以内）
  - `telop`: 画面中央の字幕（40文字以内、省略時は text）
  - `emphasis` / `se` / `reaction`: 上記の演出
- 読み間違えやすい漢字・英字は `text` 側をひらがな/カタカナにする（例: 「設定6」→「設定ろく」、「AT」→「エーティー」、「1000円」→「せんえん」）
