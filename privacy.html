プライバシーポリシー / Privacy Policy

このアプリケーション（pachislo-shorts）は、運営者本人の YouTube チャンネルと TikTok アカウントに、自動生成したショート動画をアップロードするためだけに使用する個人用ツールです。

取得する情報

Google アカウントの認可により、YouTube への動画アップロード権限（youtube.upload）のみを取得します。それ以外の個人情報やチャンネルのデータは取得・閲覧しません。

利用目的

取得した権限は、運営者のチャンネルに動画を投稿する目的にのみ使用します。

第三者への提供

取得した情報を第三者に販売・提供することはありません。認証情報は GitHub の暗号化されたシークレットにのみ保存します。

TikTok との連携

TikTok の認可により、運営者本人のアカウントの基本情報（user.info.basic）と動画投稿（video.publish）の権限のみを取得します。取得した情報は、運営者のアカウントに動画を投稿する目的にのみ使用し、保存・販売・第三者提供はしません。認証情報は GitHub の暗号化されたシークレットにのみ保存します。

Google API サービスの利用

本アプリによる Google API から取得した情報の使用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

お問い合わせ

GitHub Issues からご連絡ください。

This tool only uploads videos to the operator's own YouTube channel. It requests only the youtube.upload scope (and, for TikTok, user.info.basic and video.publish) and does not collect, sell or share any user data.
