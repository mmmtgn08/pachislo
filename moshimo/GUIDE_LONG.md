# 長尺動画 台本ガイド（週1本の自動タスクが読むファイル）

ショートで集めた視聴者に、じっくり見てもらう 8〜11 分の横長動画。
収益化の「長尺の総再生時間 4,000時間/12か月」のルートと、動画の途中の広告（8分以上で入れられる）のために作る。

**事実のルール・映像と話の一致・使えるシーンは `GUIDE.md` と同じ。必ず `GUIDE.md` も読んで従う。**
ここには長尺だけの決まりを書く。

## 動画の形
- 16:9 の横長。オープニング → 第1章 … 第N章 → エンディング
- 各章は「もしも〇〇したら」1つ分。章の始まりに扉（「第1章 月が消えたら」）が自動で入る
- 概要欄には章の目次（YouTube のチャプター）が自動で入る
- 1本のテーマでまとめる（例: 「宇宙がおかしくなったら特集」「生き物が消えたら特集」「地球の動きが変わったら特集」）

## 長さ（8分以上にする）
- ナレーションは 1秒あたり約6.5文字。**全章の `text` の合計を 3,200〜4,000 文字** にする（約9〜11分）
- 章は 4〜6 個。1章あたり 8〜14 場面、1場面の `text` は 120 文字まで
- 8分未満でも動画は作られるが、途中の広告が入らないので避ける。20分を超えるとエラー

## ショートとの違い（量産型にしない）
- ショートの台本をそのまま並べない。**ショートで扱ったネタでも、長尺では「なぜそうなるのか」を深掘りする**
  - 仕組み（例: 自転が止まると、なぜ風が吹くのか）
  - 数字の意味（例: 時速1700キロは新幹線の約5倍）
  - 意外な影響や、実際に観測されていること（NASA・気象庁などが説明している範囲で）
- 章の中の流れ: フック → 発生 → 悪化（身の回り → 街 → 地球） → **「なぜ？」の解説を2〜3場面** → とどめ → 章のまとめ
- 章の最後の場面は `earthEnd` でなくてもよい（エンディングは別に自動で入る）。`earthEnd` を使うなら1章に1回
- 章ごとに `zero_label` / `status_label` / タイマーを設定できる（ショートと同じ項目）

## 台本JSONの形式
`topics/long_sample.json` を参照（これは表示確認用の見本。本番はもっと長く、深掘りする）。

| 項目 | 内容 |
|---|---|
| `format` | `"long"` |
| `date` | 今日の日付（日本時間） |
| `title` | オープニングに出す題名（2行。`\n` で改行） |
| `youtube_title` | YouTube のタイトル（全角40文字以内）。「もしも」を入れる。`#shorts` は付けない |
| `series` | `もしも地球シリーズ` |
| `description` | 2〜3文＋「参考: 〇〇、〇〇」。章の目次は自動で足される |
| `tags` | 5〜8個（`shorts` は入れない） |
| `comment` | 投稿直後に自動で書き込むコメント（ショートと同じルール） |
| `intro_text` | オープニングのナレーション（200文字まで）。何の特集か・何章あるかを言う |
| `outro_text` | エンディングのナレーション（200文字まで）。どの章がよかったか質問＋チャンネル登録の誘い |
| `thumbnail_text` | サムネイルの文字。**2行・1行8文字まで**。一番強い言葉を2行目に（黄色になる） |
| `thumbnail_sub` | サムネイル左上の小さな札（例: 「まとめて解説」「特集」） |
| `thumbnail_scene` / `thumbnail_event` | サムネイルの背景。既定は `earthEnd` / `impact`。`space`/`meteor`、`city`/`tsunami` なども可 |
| `chapters` | 章の配列（下） |

各章:
| 項目 | 内容 |
|---|---|
| `chapter_title` | 章の名前（20文字まで。例: 「月が消えたら」） |
| `title` | 章の始めに特大で出る題名（2行） |
| `zero_label` / `status_label` / `timer_*` | ショートと同じ |
| `scenes` | 5〜20個。書き方はショートと同じ（`text` は120文字まで） |

## ネタの選び方
- `history.jsonl` の `format: "long"` の回と同じテーマは使わない
- `STATS.md` で再生の多かったショートの方向を、長尺のテーマにする（例: 生き物の回が伸びていたら「生き物が消えたら特集」）
- 章のうち1つは、まだショートでやっていないネタにする
