# 「もしも」ショート 台本ガイド（毎日の自動タスクが読むファイル）

このファイルはチャンネルの編集方針です。自由に書き換えてOK。
毎日の自動タスク（Claude）は、このガイドと `history.jsonl` を読んで台本を1本作ります。

## チャンネル像
- 一般向けの科学・雑学ショート。「もしも〇〇が消えたら / 止まったら / 2倍になったら」を3Dアニメで見せる
- ナレーターが落ち着いて事実を語り、映像で驚かせる
- 1本 30〜45秒、5〜8シーン

## 構成（毎回この流れ）
| パート | シーン | やること |
|---|---|---|
| フック | 1つ目（`earthIntro`） | 「もしも〇〇が消えたら、どうなると思う？」。タイトルが特大表示される |
| 発生 | 2つ目 | 「3、2、1、〇〇ゼロ」で始める（カウントダウンが自動で出る） |
| 展開 | 3〜5つ目 | 身近な変化 → 大きな変化の順に。1シーン1事実 |
| どんでん返し | 終盤 | 「でも実は〜」「ただし〜だったら話は別」で意外な事実を入れる |
| 締め | 最後（`earthEnd`） | 結末 ＋「次は何が〇〇したら見たい？コメントで教えて！」 |

## 事実のルール（最重要）
- **確かな科学的事実だけ**を使う。数字は教科書・公的機関レベルで裏付けがあるものだけ
- 誇張しない。「5秒」なら5秒で本当に起きる規模で語る（例: 無重力5秒で人が浮くのは約40cm）
- 映像は誇張してよいが、ナレーションとテロップは正確に
- 諸説ある・計算が怪しい内容は使わない。「〜と言われている」でごまかさない
- 怖がらせすぎない（パニック・災害の実写的な描写はしない）

## ネタの選び方
- `history.jsonl` を見て、**同じネタは二度と使わない**。直近7本と似たネタ（同じ「消える」系の連続など）も避ける
- 型をローテーションする: 「消えたら」「止まったら」「2倍になったら」「逆になったら」「なくなったら」
- コメントで多かったリクエストがあれば優先する（`requests.md` に書いてあれば使う）
- 例: 重力 / 酸素 / 月 / 太陽 / 地球の自転 / 摩擦 / 雲 / 虫 / 電気 / 海 / 音 / 色 / 南極の氷

## 使えるシーンと出来事
各シーンは `type` と `event` の組み合わせ。**同じ組み合わせを1本の中で繰り返さない**。

| type | 使える event | 映像 |
|---|---|---|
| `earthIntro` | （なし） | 宇宙から地球にズーム。必ず1つ目 |
| `city` | `stall` 車が止まり煙 / `float` 車や人が浮く / `dark` 空が暗くなり窓明かり / `freeze` 凍って雪 / `wind` 暴風で吹き飛ぶ / `rain` 雨 / `none` | 道路・ビル・車・人 |
| `fire` | `out` 火が消える / `grow` 火が大きくなる / `none` | 夜の焚き火と2人 |
| `park` | `ears` 耳をふさぐ / `cheer` 喜ぶ / `float` 浮く / `freeze` 震える / `wind` 吹き飛ぶ / `dark` 暗くなる / `rain` 雨 / `none` | 公園と3人 |
| `ocean` | `vanish` 海が消える / `float` 水が浮く / `freeze` 凍る / `wind` 大波 / `rain` 雨 / `none` | 海面と海底 |
| `underwater` | `dark` 光が届かなくなる / `freeze` 海面が凍る / `vanish` 水がなくなり魚が底へ / `none` | 海の中（魚の群れ・サンゴ・海藻・光の筋） |
| `sky` | `vanish` 雲が消える / `wind` 雲や鳥が吹き飛ぶ / `dark` 暗くなる / `freeze` 雪 / `rain` 雨 / `none` | 空（雲・鳥の群れ・飛行機） |
| `space` | `vanish` 月が消える / `dark` 太陽が暗くなる / `freeze` 地球が凍る / `float` 大気が宇宙へ / `none` | 太陽・地球・月（月の軌道つき） |
| `room` | `dark` 停電 / `float` 家具が浮く / `freeze` 部屋が凍る / `cheer` 喜ぶ / `none` | 部屋（ソファ・テレビ・照明・冷蔵庫と人） |
| `animals` | `ears` びっくり / `cheer` ジャンプ / `float` 浮く / `freeze` 震える / `wind` 吹き飛ぶ / `dark` / `rain` / `none` | 犬・猫・うさぎ |
| `crumble` | （なし） | 地面がブロック状に崩れてマグマ |
| `earthEnd` | `crumble` 砕ける / `ice` 凍る / `dark` 暗くなり街明かり / `fine` 無事 / `float` 大気が宇宙へ | 必ず最後 |

ネタに一番合う場面を選ぶ（例: 月の話なら `space`、電気の話なら `room`、生き物の話なら `animals` や `underwater`）。毎回同じ場面ばかりにならないよう、直近の動画で使った場面も見て変える。

その他の項目:
- `se`: シーン頭の効果音 `don` / `pop` / `peka` / `chan` / `boo` / `whoosh` / `kira`
- `countdown: true`: カウントダウンを出すシーン（省略時は2つ目のシーン）

- `time`: その場面が始まる時点の「物語の中の時間」（下の経過タイマー用。省略可）

見た目（時間帯・色・カメラ・切り替え演出）は日付とタイトルから自動で変わるので、指定は不要。

## 経過タイマー（画面左の大きな「経過 ○.○秒」）
「ゼロ」の瞬間に 0 から始まり、最後の場面（`earthEnd`）が始まる時点で `timer_duration` に到達する。
ナレーションが「約1.3秒後」のように時刻に触れる場面には、その場面に `time: 1.3` を付けて表示と内容を合わせる（数字は事実どおりに）。
- `timer_duration`: 物語の長さ（既定 5）。`0` にするとタイマーを出さない
- `timer_decimals`: 小数点以下の桁数 0〜2（既定 1）。一瞬の出来事を扱うなら 2、長い時間なら 0
- `timer_unit`: 単位（既定「秒」。「分」「日」「年」なども可）
- `timer_label`: 円の中の文字（既定「経過」）

## 台本JSONの形式
`topics/oxygen.json` と `topics/gravity.json` を参照。
- `date`: 今日の日付（日本時間）
- `title`: 動画内のタイトル。「もしも地球から5秒間\n〇〇が消えたら」のように2行
- `youtube_title`: YouTube のタイトル（全角35文字以内。「#shorts」は自動付与）
- `series`: `もしも地球シリーズ`（回数は自動で数える）
- `zero_label`: カウントダウン後の大きな表示（例: 「酸素 0%」「重力 0」）
- `status_label`: 右上に出続けるバッジ（例: 「O₂ 0%」「重力 0G」、8文字以内）
- `timer_duration` / `timer_decimals` / `timer_unit` / `timer_label`: 左の経過タイマー（下記）
- `description`: 1〜2文。最後にコメント誘導
- `tags`: 5〜8個
- `scenes`: 5〜8個（最大12）
  - `text`: ナレーション（1シーン80文字以内、全体で45秒以内に収まる長さ）
  - `telop`: 画面中央の字幕（2行。1行目＝状況、2行目＝結果。2行目は強調色になる）
- 数字や英字は読み間違えやすいので `text` 側はひらがな・カタカナにする（例: 「40cm」→「40センチ」）
