# 「もしも」ショート 台本ガイド（毎日の自動タスクが読むファイル）

このファイルはチャンネルの編集方針です。自由に書き換えてOK。
毎日の自動タスク（Claude）は、このガイドと `history.jsonl` を読んで台本を1本作ります。

## チャンネル像
- 一般向けの科学ショート。「もしも〇〇が消えたら / 止まったら / 2倍になったら」で、**地球や世界が大きく変わっていく様子**を3Dアニメで見せる
- **毎回ド派手に。** 「結局ほとんど変わらない」「5秒なら平気」で終わるネタは選ばない。最後は地球が凍る・砕ける・暗くなる・大気が宇宙へ逃げる、くらいの大変化まで行ってよい
- ナレーターは落ち着いて事実を語り、映像はどんどんスケールアップさせて驚かせる
- 1本 30〜45秒、5〜8シーン

## 構成（毎回この流れ）
| パート | シーン | やること |
|---|---|---|
| フック | 1つ目（`earthIntro`） | 「もしも〇〇が消えたら、どうなると思う？」。タイトルが特大表示される |
| 発生 | 2つ目 | 「3、2、1、〇〇ゼロ」で始める（カウントダウンが自動で出る）。**この時点でもう何かが起きる** |
| 悪化 | 3〜5つ目 | **場面ごとに規模を大きくする**: 身の回り → 街 → 海や空 → 地球規模。毎場面で前より大きな変化を見せる |
| とどめ | 終盤 | 「さらに」「そして」で一番大きな変化。どんでん返しを入れるなら「もっとヤバい事実」にする（「でも平気」で落とさない） |
| 締め | 最後（`earthEnd`） | **大変化した地球**（`crumble` / `ice` / `dark` / `float`）＋「次は何が〇〇したら見たい？コメントで教えて！」。`fine` は原則使わない |

## 時間の長さ
- 「5秒間」にこだわらない。**大変化が起きる長さを選ぶ**
  - 一瞬で大惨事になるもの → 5秒・1秒（例: 自転が止まる、空気が消える）
  - じわじわ悪化するもの → 「ずっと」「永遠に」にして、タイマーを分・日・年で進める（例: 太陽が消えたら 8分20秒 → 1週間 → 1年）
- タイトルも長さに合わせる（「もしも太陽が永遠に消えたら」「もしも地球の自転が1秒止まったら」など）
- 左のタイマーは `timer_duration` と `timer_unit` で合わせ、各場面の `time` でその場面の時点を示す

## 事実のルール（最重要）
- 映像は大げさでいいが、**ナレーションとテロップの中身は科学的に正しいこと**
- 数字は教科書・公的機関・有名な試算（NASA、気象庁、大学の解説など）レベルで裏付けがあるものだけ
  - 試算の数字を使うときは「計算では」「目安で」と添える。出どころの怪しい数字は使わない
- 大変化は「科学的にそうなる」と説明できる範囲で描く（物理の法則に反するオチ・作り話はしない）
- 誇張しない。規模や速さは事実どおり（例: 赤道での自転の速さは時速約1700km）
- 実際の災害の被害者や実在の事件を連想させる表現、残酷な描写はしない。滅亡はあくまで「地球規模の現象」として見せる
- **映像の順番もナレーションの時系列に合わせる**。ナレーションで「まだ起きていない」ことを、先に映像で見せない
  - 例（ダメ）: 太陽の光が止まった直後に空が暗くなる映像 → 最後に「暗くなるのは約8分20秒後」と種明かし（視聴者には間違いに見える）
  - 例（良い）: 「止まった瞬間は、まだ何も起きない」（`event: none`）→ タイマーを `time` で進めて「8分20秒後、ここで初めて暗くなる」（`event: dark`）
- 各場面の `event` は、その場面のナレーションが言っている時点で本当に起きていることだけにする

## ネタの選び方
- `history.jsonl` を見て、**同じネタは二度と使わない**。直近7本と似たネタも避ける
- **大きく変化するネタを選ぶ**（地球規模の変化、生き物が住めなくなる、星としての姿が変わる、など）
- 型をローテーションする: 「消えたら」「止まったら」「2倍になったら」「半分になったら」「近づいたら」「ずっと続いたら」
- コメントで多かったリクエストがあれば優先する（`requests.md` に書いてあれば使う）
- ネタの例: 地球の自転が止まったら / 太陽が永遠に消えたら / 大気が消えたら / 月が消えたら（ずっと） / 重力が2倍になったら / 地球が太陽に少し近づいたら / 地球の磁場が消えたら / 海が全部蒸発したら / 地球の中心が冷えたら / 南極の氷が全部とけたら
- 「結局ほとんど何も起きない」ネタ（短時間の雲・停電など）は使わない

## 使えるシーンと出来事
各シーンは `type` と `event` の組み合わせ。**同じ組み合わせを1本の中で繰り返さない**。

| type | 使える event | 映像 |
|---|---|---|
| `earthIntro` | （なし） | 宇宙から地球にズーム。必ず1つ目 |
| `city` | `stall` 車が止まり煙 / `float` 車や人が浮く / `dark` 空が暗くなり窓明かり / `freeze` 凍って雪 / `wind` 暴風で吹き飛ぶ / `rain` 雨 / **`meteor` 隕石が降る / `explode` 大爆発 / `tsunami` 巨大津波が街を飲み込む / `burn` 街が炎上** / `none` | 道路・ビル・車・人 |
| `fire` | `out` 火が消える / `grow` 火が大きくなる / `none` | 夜の焚き火と2人 |
| `park` | `ears` 耳をふさぐ / `cheer` 喜ぶ / `float` 浮く / `freeze` 震える / `wind` 吹き飛ぶ / `dark` 暗くなる / `rain` 雨 / **`meteor` / `explode` / `burn` 森が燃える** / `none` | 公園と3人 |
| `ocean` | `vanish` 海が消える / `float` 水が浮く / `freeze` 凍る / `wind` 大波 / `rain` 雨 / **`tsunami` 巨大津波が迫る / `meteor` 海に隕石** / `none` | 海面と海底 |
| `underwater` | `dark` 光が届かなくなる / `freeze` 海面が凍る / `vanish` 水がなくなり魚が底へ / `none` | 海の中（魚の群れ・サンゴ・海藻・光の筋） |
| `sky` | `vanish` 雲が消える / `wind` 雲や鳥が吹き飛ぶ / `dark` 暗くなる / `freeze` 雪 / `rain` 雨 / `none` | 空（雲・鳥の群れ・飛行機） |
| `space` | `vanish` 月が消える / `dark` 太陽が暗くなる / `freeze` 地球が凍る / `float` 大気が宇宙へ / **`meteor` 小惑星が地球に衝突** / `none` | 太陽・地球・月（月の軌道つき） |
| `room` | `dark` 停電 / `float` 家具が浮く / `freeze` 部屋が凍る / `cheer` 喜ぶ / `none` | 部屋（ソファ・テレビ・照明・冷蔵庫と人） |
| `animals` | `ears` びっくり / `cheer` ジャンプ / `float` 浮く / `freeze` 震える / `wind` 吹き飛ぶ / `dark` / `rain` / **`meteor` / `explode` / `burn`** / `none` | 犬・猫・うさぎ |
| `crumble` | （なし） | 地面がブロック状に崩れてマグマ |
| `earthEnd` | `crumble` 砕ける / `ice` 凍る / `dark` 暗くなり街明かり / `float` 大気が宇宙へ / **`impact` 巨大隕石が衝突して砕ける / `burn` 地表が真っ赤に焼ける** / `fine` 無事（原則使わない） | 必ず最後 |

`meteor` / `explode` / `impact` では画面が揺れる。大惨事の演出は、ナレーションでその出来事が起きた場面だけに使う（起きていない爆発や津波を見せない）。

ネタに一番合う場面を選ぶ（例: 月の話なら `space`、電気の話なら `room`、生き物の話なら `animals` や `underwater`）。毎回同じ場面ばかりにならないよう、直近の動画で使った場面も見て変える。

その他の項目:
- `se`: シーン頭の効果音 `don` / `pop` / `peka` / `chan` / `boo` / `whoosh` / `kira`
- `countdown: true`: カウントダウンを出すシーン（省略時は2つ目のシーン）

- `time`: その場面が始まる時点の「物語の中の時間」（下の経過タイマー用。省略可）

見た目（時間帯・色・カメラ・切り替え演出）は日付とタイトルから自動で変わるので、指定は不要。

## 経過タイマー（画面左の大きな「経過 ○.○秒」）
「ゼロ」の瞬間に 0 から始まり、最後の場面（`earthEnd`）が始まる時点で `timer_duration` に到達する。
ナレーションが「約1.3秒後」のように時刻に触れる場面には、その場面に `time: 1.3` を付けて表示と内容を合わせる（数字は事実どおりに）。
- `timer_duration`: 物語の長さ（既定 5）。`0` にするとタイマーを出さない
- `timer_decimals`: 小数点以下の桁数 0〜2（既定 1）。一瞬の出来事を扱うなら 2、長い時間なら 0
- `timer_unit`: 単位（既定「秒」。「分」「日」「年」なども可）
- `timer_label`: 円の中の文字（既定「経過」）

## 台本JSONの形式
`topics/oxygen.json` と `topics/gravity.json` を参照。
- `date`: 今日の日付（日本時間）
- `title`: 動画内のタイトル。「もしも地球から5秒間\n〇〇が消えたら」のように2行
- `youtube_title`: YouTube のタイトル（全角35文字以内。「#shorts」は自動付与）
- `series`: `もしも地球シリーズ`（回数は自動で数える）
- `zero_label`: カウントダウン後の大きな表示（例: 「酸素 0%」「重力 0」）
- `status_label`: 右上に出続けるバッジ（例: 「O₂ 0%」「重力 0G」、8文字以内）
- `timer_duration` / `timer_decimals` / `timer_unit` / `timer_label`: 左の経過タイマー（下記）
- `description`: 1〜2文。最後にコメント誘導
- `tags`: 5〜8個
- `scenes`: 5〜8個（最大12）
  - `text`: ナレーション（1シーン80文字以内、全体で45秒以内に収まる長さ）
  - `telop`: 画面中央の字幕（2行。1行目＝状況、2行目＝結果。2行目は強調色になる）
- 数字や英字は読み間違えやすいので `text` 側はひらがな・カタカナにする（例: 「40cm」→「40センチ」）
