# いきもの雑学ショート 台本ガイド（毎日の自動タスクが読むファイル）

新チャンネル（実写）の編集方針です。自由に書き換えてOK。
毎日の自動タスク（Claude）は、このガイドと `history.jsonl` を読んで台本を1本作ります。

## チャンネル像
- 動物・自然の**実話の雑学**ショート。「へぇ〜！」「知らなかった」と言わせる
- 映像は Pixabay（と Pexels）の**実写素材**（自動で検索・取得）。AI生成映像は使わない
- ナレーションは明るく親しみやすく、テンポよく。1本 **25〜40秒**、5〜7シーン
- 「もしも3D」チャンネル（空想・3Dアニメ）とは別物。空想や「もしも」は扱わない

## 構成の型（毎回ローテーションする）
直近3本と同じ `format` は使わない。

| format | 流れ | 例 |
|---|---|---|
| `list` | フック → ①②③ → 締め | タコの体、ヤバすぎる3つのヒミツ |
| `ranking` | フック → 第3位 → 第2位 → 第1位 → 締め | 睡眠時間が短すぎる動物ランキング |
| `quiz` | 問題 → 考える間（「答えは…」）→ 正解 → 理由 → 締め | ラッコが寝るとき体に巻くものは？ |
| `myth` | よくある勘違い → 「実は…」→ 本当の理由 → 締め | 「ダチョウは砂に頭を隠す」は本当？ |
| `single` | 1つの驚きの事実を深掘り | 雷は地球で1秒に何回落ちている？ |

- `step` を付けたシーンだけ「ヒミツ②/3」のカウンターと、切り替わり時の大きな表示が出る。`quiz` / `myth` / `single` では `step` を付けない（カウンターが出ない）
- `ranking` では `step` に**順位の数字**を付ける（3 → 2 → 1）。画面には「第3位」と出る。`step_label` は不要
- `list` では `step_label` は「ヒミツ」「ポイント」「理由」など内容に合う2〜4文字

## 最初の2秒（最重要）
- 1シーン目は**一番驚く事実を先に言い切る**か、答えたくなる質問にする。前置き・あいさつ禁止
  - 良い: 「タコの心臓、実は3つあるって知ってた？」「キリンが眠るのは、1日たった数十分」
  - ダメ: 「今日はタコについて紹介します」
- 1シーン目の `telop` は空にする（タイトルが特大表示される）

## 事実のルール（最重要）
- **図鑑・大学・博物館・公的機関（環境省、NOAA、Smithsonian、National Geographic など）で確認できる事実だけ**を使う
- ネットでよく見るが不正確な俗説は、本当の部分だけに直すか使わない
  - 例: 「ラッコはいつも手をつないで寝る」→ 実際は海藻を体に巻いたり、仲間と寄り集まったりすることが多い
  - 例: 「金魚の記憶は3秒」→ 誤り（`myth` 型で正すネタにするのはOK）
- 数字は幅があるものは「約」「〜ほど」「種類によっては」を付ける。動物の種類で違う場合は、どの種類の話かを言う
- 残酷な捕食シーン・死骸・ケガの描写や、それを想像させる検索語は使わない

## 映像（素材検索）のルール
各シーンの `query` が英語の検索語。**ナレーションの主語が画面に映る検索語にする。**
- 動物名＋動き/部位で具体的に: `octopus swimming`, `giraffe eating leaves`, `sea otter floating`
- `alt` に予備の検索語を2〜3個（だんだん広く: `octopus tentacles` → `octopus` → `ocean underwater`）
- 検索で素材が少ない動物（珍しい深海魚・特定の昆虫など）はネタにしない。Pixabay で十分ありそうな、よく知られた動物を選ぶ
- Pixabay の検索はシンプルな語のほうが当たりやすい（`octopus`, `octopus sea` など2語程度）。`alt` の最後は動物名1語にする
  - 素材が多い例: 犬, 猫, ライオン, ゾウ, キリン, ペンギン, イルカ, クジラ, タコ, クラゲ, サメ, ウミガメ, ラッコ, パンダ, コアラ, フクロウ, ハチ, チョウ, カメレオン, 馬, 牛, ワシ, オオカミ, 雷, 火山, オーロラ, 滝, 雪
- 同じ動画の中で同じ検索語を繰り返さない（同じ映像になりやすい）
- 人の顔が大きく映りそうな検索語（`zookeeper`, `people` など）は使わない
- `start`（任意）: 素材の何秒目から使うか（既定 0.5）

## ネタの選び方
- `history.jsonl` の `animal` を見て、**直近14本と同じ動物は使わない**。同じ雑学は二度と使わない
- 動物 6〜7割、自然（天気・海・火山・植物など）3〜4割くらい
- `requests.md` にリクエストがあれば優先する

## 台本JSONの形式
`topics/tako.json` を参照。
- `date`: 今日の日付（日本時間）
- `format`: `list` / `ranking` / `quiz` / `myth` / `single`
- `animal`: 主役の生き物・自然現象（履歴でかぶりを避けるため）
- `title`: 動画内のタイトル。2行（`\n` で区切る）。2行目が強調色になる
- `youtube_title`: YouTube のタイトル（全角35文字以内。「#shorts」は自動付与）
- `series`: `いきもの雑学`
- `step_label`: カウンターの文字（`list` / `ranking` のときだけ）
- `description`: 1〜2文。最後にコメント誘導
- `comment`: 投稿直後にチャンネルから書き込むコメント。**答えやすい質問**、60文字以内、リンクなし、絵文字0〜1個。必ず入れる
- `tags`: 5〜8個（`shorts` を含める）
- `scenes`: 4〜10個（おすすめ 5〜7）
  - `text`: ナレーション（90文字以内。全体で40秒以内に収まる長さ）。数字や英字は読み間違えやすいので**ひらがな・カタカナ**で書く（「3分の2」→「3ぶんの2」でもOK、「40cm」→「40センチ」）
  - `telop`: 画面の字幕（1〜2行）。**一番伝えたい言葉を【】で囲む**と黄色で大きくなる。1シーン1か所まで
  - `query` / `alt`: 素材の検索語（英語）
  - `step`: 何個目か（`list` / `ranking` のみ）
  - `se`: 効果音 `don` / `pop` / `peka` / `chan` / `boo` / `whoosh` / `kira`
- 最後のシーンはコメント誘導（「次はどの生き物が知りたい？コメントで教えて！」など、毎回言い方を変える）
