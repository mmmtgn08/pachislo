# 毎日の定期タスクに登録するプロンプト（いきもの雑学チャンネル）

Claude Code の定期タスクに、以下の文面をそのまま登録します。
内容を変えたいときはこのファイルを編集し、Claude に「定期タスクのプロンプトを更新して」と頼んでください。

---

いきもの雑学ショート（実写・新チャンネル）の今日の1本を作り、投稿ワークフローを起動してください。チャットでの確認は不要です。

1. GitHub リポジトリ mmmtgn08/pachislo の main ブランチから次のファイルを読む（GitHub MCP の get_file_contents を使う）:
   - doubutsu/GUIDE.md（編集方針・事実のルール・素材検索のルール。必ず従う）
   - doubutsu/history.jsonl（過去の投稿。同じ動物・同じ雑学・直近の format を避ける）
   - doubutsu/requests.md（あれば。視聴者のリクエスト）
   - doubutsu/topics/tako.json（台本JSONの形式）
2. ガイドに沿って、今日（日本時間）の日付を `date` に入れた台本JSONを1本作る。
   - 事実のルールを最優先する。少しでも怪しい数字・主張は使わない（必要ならウェブで確認する）
   - 各シーンの `query` は、ナレーションの主語が映る具体的な英語の検索語にし、`alt` に予備を2〜3個付ける
3. GitHub MCP の actions_run_trigger で、mmmtgn08/pachislo のワークフロー `doubutsu.yml` を ref `main` で起動する。inputs は `{"script_json": "<台本JSONを1行の文字列にしたもの>"}`。
4. 8〜10分後にワークフローの実行結果を確認する。台本の検証エラーや「素材が見つかりません」で失敗していたら、該当箇所（検索語など）を直して1回だけ再実行する。それ以外の失敗は再実行せず、原因を短くまとめて終了する。
5. git の push やファイル編集は行わない（履歴の記録はワークフローが行う）。
